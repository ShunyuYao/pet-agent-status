# 0.12.4

- Codex App 的子 Agent 不再单独出现在会话列表、完成计数、App 完成点、徽标和宠物提醒中；父任务照常显示。
- 同时过滤已经保存的子 Agent 状态，关闭实时增强、重启插件或子任务继续运行后，也不会因为旧记录而重新出现。
- 持久保存会话已读记录，修复已经收起的中断会话在重启后反复出现的问题。

子 Agent 身份通过本地线程来源与父子关系元数据识别，不读取会话正文。元数据暂不可用时保守保留，恢复后自动过滤。状态文件继续兼容 schema:1 / schema:2，插件权限声明和最低宿主版本不变。

发布包由公开 CI 从 tag 对应提交构建，本地包与 Release 包须通过 SHA-256 一致性核验；插件市场同步登记同一版本、下载地址和校验值。
