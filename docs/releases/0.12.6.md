# 0.12.6

- 修复 Codex App 历史会话在内部执行 ID 改变后，续聊仍在运行却不显示在插件中的问题。
- 通过本地索引登记且校验过的记录文件路径，关联原会话 ID 与当前执行 ID；面板和跳转仍保留原会话，不产生重复任务。
- 保留正常完成、已读、重启后的状态保护以及子 Agent 过滤，避免旧回合的中断或完成状态挡住新一轮续聊。

此版本只调整状态元数据关联，不读取会话正文。插件权限、最低宿主版本和状态文件格式保持兼容（schema:1 / schema:2）。

Fixes resumed historical Codex App sessions disappearing while running after their internal runtime ID changes. The plugin resolves the current runtime from the validated, indexed record path while preserving the original session in the panel and navigation. Completion, read-state, restart protections, and subagent filtering remain intact. No conversation content is read, and permissions and state-file compatibility are unchanged.

发布包由公开 CI 从 tag 对应提交构建，本地包与 Release 包须通过 SHA-256 一致性核验；插件市场同步登记同一版本、下载地址和校验值。
