# 0.12.5

- 修复 Codex App 同一会话的排队 prompt 已开始执行，但插件误判为已完成、随后从列表消失的问题。
- 收到未读完成通知时，先核验回合是否结束，避免上一轮的迟到通知覆盖正在运行的后续回合；数据库更新稍晚时会保留通知并继续核验。
- 保留正常完成后的气泡和徽标提醒、已读收起、旧任务续聊、完成后防重复出现，以及子 Agent 过滤。

此版本只调整状态判定，不读取会话正文。插件权限、最低宿主版本及状态文件格式保持兼容（schema:1 / schema:2）。

Fixes queued follow-up prompts in Codex App disappearing from the session list while still running. Completion notifications now wait for turn metadata to confirm that the turn has ended, preventing a delayed notification from marking an active continuation as complete.

发布包由公开 CI 从 tag 对应提交构建，本地包与 Release 包须通过 SHA-256 一致性核验；插件市场同步登记同一版本、下载地址和校验值。
