# 0.13.2 — 本地诊断日志与 Codex 连接恢复

- 新增本地诊断日志，记录启动、连接异常、重试与恢复、状态采集故障和每分钟健康摘要。日志位于 `~/.local/state/pet-agent-status/diagnostics/`，重启保留，三份文件总计最多 3 MiB。
- 修复 Codex App 握手超时后永久停用的问题。现在与普通断线一样，按 1、5、15、60 秒退避重连；成功握手后重置退避。
- 损坏 JSON 或超过 1 MiB 的协议帧仍会停止监听，但会记录明确原因。此时可关闭再开启设置中的 Codex App 实时增强。
- 日志仅保存固定诊断字段，不记录会话正文、标题、路径、原始载荷或错误堆栈，不上传数据；日志写入失败不影响采集。插件权限及状态文件 schema:3 不变，继续兼容读取 schema:1/2。

## English

Adds bounded local diagnostics for connection failures, retries, recovery, collection faults and periodic health summaries. Logs survive restarts and rotate across three files totaling at most 3 MiB.

Codex App handshake timeouts now retry with 1/5/15/60-second backoff instead of permanently disabling the connection. Malformed JSON and oversized frames still stop the listener, with an explicit logged cause; toggle the enhancement off and on to reconnect.

No conversation content, titles, paths, raw payloads or error stacks are logged or uploaded. Logging failures do not interrupt collection. No new permissions or state-schema changes.
